# Editorial Mood replaces tag-filter Mood

The Mood concept is redefined from a transparent tag/genre filter (`HasGenre(mood) OR HasTag(mood) + PlaytimeBetween(0,120)`) to a set of named, curated playlists with hidden selection criteria — the Spotify editorial playlist model. The user sees evocative names ("Today's Biggest Hits", "Friday Party", "Deck Guardians"); the underlying logic is Vapourfly's editorial judgment, not a user-configured filter. Seven canonical moods are defined, each backed by criteria computable from Vapourfly's data sources. The old `collections dynamic mood` CLI command and GUI entry are replaced by a mood-selection interface. Trade-off: users lose the ability to filter by arbitrary tags through the Mood interface (they can still use rule-based playlists for that), but gain the curated, low-effort "just pick a vibe" experience that matches the product's Spotify-like positioning.
