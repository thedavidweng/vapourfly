# Write surface limited to cloud-storage-namespace-1.json

Vapourfly only ever writes `userdata/<account>/config/cloudstorage/cloud-storage-namespace-1.json`. `localconfig.vdf` is read-only forever (parsed for playtime and per-app state, never written). Vapourfly stays within the PRD's feature scope — junk hide, collections, recommendation collection, playlist sync — all of which Steam stores in cloud storage. Editing per-app Steam settings (tags, launch options, controller configs) is explicitly out of scope. This specialises the safety model, backup strategy, and "Steam running" guard to one file, minimising blast radius. The original PRD said "writes to localconfig.vdf"; that was wrong — modern Steam stores collections and the Hidden state in cloud storage, not localconfig.
