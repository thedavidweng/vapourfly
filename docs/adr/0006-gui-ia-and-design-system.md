# GUI information architecture and design system

The Vapourfly desktop GUI uses the supplied light desktop mockups as the default source of truth for chrome and navigation, with a runtime switch to the earlier dark design-system shell. Light mode uses a warm near-white canvas, white bordered cards, and a restrained orchid accent. Dark mode restores the cool surface hierarchy and violet brand accent from the original ADR-0006 shell. Both modes share the same structural tokens, components, hierarchy, and layout regions; only palette values change. Desktop top chrome with breadcrumb and metrics; native OS window controls remain authoritative — the app does not draw its own traffic-light circles. Monochrome line icons remain common. Fidelity is structural while egui retains native sizing and input behavior. Theme mode is toggled from the top chrome and persists across launches via eframe application storage (not domain config).

Top-level destinations are Library, Collections, Recommendations, Playlists, Discover, Data Sources, and Settings. Discover is a first-class destination. Junk is a Library workflow with mode, preview, collection, and hide actions. Backups and restore live under Settings. Domain concepts and safety behavior remain unchanged: Playlist and Steam Collection stay distinct, every Steam write stays confirmation-gated, and hydration behavior remains the same.
