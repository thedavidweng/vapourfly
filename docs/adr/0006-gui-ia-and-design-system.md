# GUI information architecture and design system

The Vapourfly desktop GUI adopts a fixed information architecture and dark design system from the product mockups as the source of truth for chrome and navigation—not merely a restyle of the previous map. Top-level destinations are Library, Collections, Recommendations, Playlists, Discover, Data Sources, and Settings. Discover is a first-class destination (it no longer lives only inside Playlists). Junk is not a sidebar item: full Junk capability (mode, preview, apply to Steam Collection, hide) is a Library workflow. Backups and restore live under Settings, not a top-level Backups view. The shell uses dark design tokens and monochrome line icons; fidelity is structural (tokens, components, layout regions), not pixel-perfect. Trade-off: users who relied on top-level Junk/Backups or Discover-inside-Playlists must relearn entry points, but the product map matches the designed surface and stops burying generators and maintenance tools inconsistently. Domain concepts (Playlist vs Steam Collection, write safety, hydration) are unchanged—only placement and presentation move.
