# Third-Party Notices

This project includes reference code and data from the following third-party sources under `reference/`. These files are used for development reference only and are not distributed with Vapourfly releases.

## reference/depressurizer/

Source: [Depressurizer](https://github.com/Depressurizer/Depressurizer)
License: GPL-2.0
Files: VDF parser, GameData, GameDB, AutoCat, Profile, URL constants

## reference/gameloop-vdf/

Source: [gameloop-vdf](https://github.com/nicknash/gameloop-vdf) (C# Text VDF library)
License: MIT
Files: Text VDF tokenizer, parser, writer, format constants (15 C# source files)

## reference/steam-samples/

Source: Local macOS Steam installation data (sanitized)
License: N/A (user-generated data samples)
Files: Real VDF and JSON files used as test fixtures

## reference/steamtools/

Source: [SteamTools](https.com/rmbadmin/SteamTools) (BD.SteamClient components)
License: MIT
Files: VDF parsers, Steam path detection, SteamApp model, Steamworks IPC

## reference/tinywii/

Source: [TinyWiiBackupManager](https://github.com/nicknash/TinyWiiBackupManager)
License: MIT
Files: Rust workspace structure, game model, HTTP client, UI patterns
